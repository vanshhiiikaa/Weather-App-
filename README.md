# 🌦️ Weather App

A responsive Weather App built using HTML, CSS, and JavaScript that allows users to search for a city and view its current weather information using the Open-Meteo API.

## ✨ Features

- 🔍 Search for weather by city name
- 🌡️ Display current temperature in Celsius
- ☁️ Show weather conditions with emojis
- 💧 Display relative humidity
- 💨 Display wind speed in km/h
- 🌙 Show a moon icon for clear nighttime conditions
- ⚠️ Handle invalid city names and API errors
- ⌨️ Search using the button or Enter key
- 📱 Responsive design for mobile and desktop
- 🌐 Fetch weather data without an API key for non-commercial use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Ensure all three files are in the same folder.
4. Open `index.html` in your web browser.
5. Enter a city name in the search box.
6. Click **Search** or press Enter to view the weather.

**Note:** An internet connection is required to fetch weather data.

## 🌐 APIs Used

### 1. Open-Meteo Geocoding API

Converts city names into geographical coordinates.

https://geocoding-api.open-meteo.com/v1/search

### 2. Open-Meteo Weather API

Provides current temperature, humidity, wind speed, and weather conditions.

https://api.open-meteo.com/v1/forecast

Documentation: https://open-meteo.com/en/docs
